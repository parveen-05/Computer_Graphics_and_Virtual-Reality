2. Open IDLE.
3. Select **File → Open** and open `main.py`.
4. Select **Run → Run Module**, or press **F5**.
5. A window should appear showing the DDA line on the left and Bresenham line on the right.
6. The IDLE Shell prints the number of pixels plotted by each algorithm.
7. Close the graphics window when finished.

## Algorithms

### DDA
1. Read the two endpoints.
2. Calculate `dx = x2 - x1` and `dy = y2 - y1`.
3. Set `steps = max(|dx|, |dy|)`.
4. Calculate `x_increment = dx / steps` and `y_increment = dy / steps`.
5. Starting at the first endpoint, plot rounded x and y coordinates and increment them until all steps are completed.

### Bresenham
1. Calculate `dx`, `dy`, and the direction signs.
2. Initialize the error value as `dx - dy`.
3. Plot the current pixel.
4. Use integer error comparisons to decide whether x, y, or both coordinates should advance.
5. Stop after plotting the second endpoint.

## DDA vs Bresenham
| DDA | Bresenham |
|---|---|
| Uses floating-point increments | Uses integer error updates |
| Rounds generated coordinates | Chooses pixels using an error term |
| Straightforward incremental method | Generally more efficient for raster line drawing |
